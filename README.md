# Jarvis AI Assistant

A locally running AI assistant with:

- Persistent semantic memory
- Editable long-term memory
- Dynamic tool routing
- Multi-step action execution
- Browser/app control
- YouTube playback
- Vector database memory system
- Modular agent architecture

## Features

### Memory System
- Long-term semantic memory
- Memory retrieval
- Memory deletion
- Multi-memory extraction
- Memory filtering
- Persistent vector database

### Action System
- Open websites
- Launch applications
- Play YouTube videos
- Google search
- YouTube search
- Multi-step actions
- Dynamic parameter extraction

## Tech Stack

- Python
- Ollama
- Mistral AI
- ChromaDB
- Sentence Transformers
- PyQt6
- Edge-TTS
- PyInstaller
- Inno Setup

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Ollama:

```bash
ollama run mistral
```

Run Jarvis:

```bash
python main.py
```
